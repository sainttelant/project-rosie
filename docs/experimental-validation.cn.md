# 实验验证与判读框架

本项目输出仅为研究候选设计。结合预测、GC 达标、序列完整或结构预测均不能证明抗原呈递、T 细胞反应或疗效。以下是供具备资质的实验室审查的验证框架，不是已验证的 SOP，也不包含可直接用于临床的剂量或统一阳性阈值。人源或犬源样本须经过相应伦理审批、知情同意及生物安全评估。

## 验证顺序

1. 核对输入变异、正常对照、物种和受试者 MHC 分型；犬 DLA 不得用人 HLA 代替。独立检查 FASTA、翻译产物、CDS 坐标、UTR 来源及 Poly-A 区段长度。
2. 由合格实验室确认 RNA 身份、完整性、尾长、杂质和细胞表达；以匹配的空载体或无关构建作为对照，记录毒性和转染差异。序列设计不代表制剂质量已达标。
3. 对突变肽与野生型肽进行配对免疫学评估，必要时增加直接结合或免疫肽组学证据。肽刺激阳性不能单独证明完整 mRNA 能被加工呈递。
4. 用不同原理的检测交叉验证，并区分 CD8 与 CD4 反应；临床研究之前还需独立安全性与有效性评估。

## ELISPOT / FluoroSpot

**所需材料类别：** 经审批获取且 MHC 分型明确的 PBMC 或 T 细胞/APC 体系、突变肽与配对野生型肽、无关肽、物种适配的 IFN-γ 检测试剂与板、经验证的阳性刺激对照、活率检测及斑点读板设备。犬样本必须确认试剂对犬细胞因子的适配性。

**简要流程：** 在经批准的实验室 SOP 下设置背景、无关肽、野生型肽、突变肽和阳性对照，进行独立重复；记录细胞活率、有效细胞数和批次后检测反应。按预先固定的读板规则计数，比较突变与野生型及背景，并用独立实验复核。

**预期读数与判读：** 报告每百万有效细胞的斑点形成单位、背景扣除值、相对对照变化和重复间不确定性。阳性必须同时满足预先规定的绝对检测下限、相对背景标准、有效阳性对照及重复一致性。阈值应由该物种、试剂和实验室的阴性样本分布建立，不应把任意 SFU 或倍数当作通用临床阈值。无反应也可能源于样本活率、呈递或检测灵敏度问题。

## MHC 四聚体 / 多聚体染色

**所需材料类别：** 与实际 HLA/DLA 分型及目标肽匹配的 MHC 多聚体、无关肽多聚体对照、经验证的物种适配 CD3/CD4/CD8 及活死染色试剂、流式细胞仪与补偿/FMO 对照。犬源或 MHC-II 多聚体的制备和可获得性须先确认，不能假设现成人源试剂可替代。

**简要流程：** 根据合格实验室的染色和质控 SOP，用对照建立补偿与门控，区分活细胞、单细胞及相应 T 细胞亚群；比较目标和无关多聚体的结合比例，并在独立重复中确认。

**预期读数与判读：** 报告目标亚群中多聚体阳性比例、有效事件数、阴性对照分布及检测限。阳性比例必须超出预先确定的背景界限，并满足最低有效事件数和重复一致性标准；具体数值应在正式检测前完成实验室验证。多聚体结合只提示识别，不等同于细胞因子释放或肿瘤杀伤，需要功能试验交叉确认。

## MHC-II 与 CD4 辅助肽

MHC-II 预测输出独立于原有 MHC-I 排名；报告中的前 20 行只是未筛选预览，不是已验证的 CD4 表位。辅助肽默认不编码；启用 PADRE 或自定义肽后，须独立验证受试者 MHC-II 支持、加工呈递、CD4 反应与潜在非目标反应。PADRE 的人源研究背景不能被外推为犬源有效性。AAY 连接子及已有 CTL 设计也不能证明 MHC-II 加工路径有效。
