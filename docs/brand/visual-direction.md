# Project Rosie visual direction

## The idea

Project Rosie should look like a calm editorial explainer, not a generic biotech startup.

The recurring device is an original, minimal cartoon of Rosie: a friendly black Labrador helping make a difficult biological idea legible. Each image should communicate one idea before a reader reaches the headline.

This system must be original. It can use the *qualities* of an editorial single-panel cartoon—restraint, a single visual premise, ink linework, and a little warmth—but must not imitate a particular artist, publication, or existing cartoon.

## Core palette

| Role | Value |
| --- | --- |
| Paper background | `#F6F3EC` |
| Ink | `#171717` |
| Supporting gray | `#A8A39A` |

Do not use orange in Project Rosie brand artwork. Avoid bright gradients and the usual blue-purple “AI biotech” visual language. Rosie remains dark charcoal/black; that is the visual anchor across the series.

## Illustration rules

- Use warm off-white paper, black pen-and-ink linework, and only light gray wash shading.
- Show Rosie as a friendly black Labrador with an understated collar and tag. Keep the pose and face approachable, curious, and thoughtful.
- Use one visual metaphor per cover. Prefer ordinary objects—funnels, roadmaps, maps, magnifying glasses—combined with simple biology symbols.
- Keep the right third substantially empty so the publishing surface can add a real, accessible headline in HTML or design software.
- Do not put generated text, logos, watermarks, medical gore, syringes, or photorealistic imagery in the illustration.
- Design at 1.91:1 for Open Graph and social previews (1200 × 630 when exported for production).

## Future cover checklist

1. State the post’s one-sentence premise.
2. Turn that premise into one visual metaphor, not an infographic.
3. Keep Rosie recognisable and the right third open for the title.
4. Use the three-color system only.
5. Export an Open Graph-safe landscape asset and provide meaningful alt text.
